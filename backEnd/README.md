# QueryMind AI — Backend

## Overview
This directory will contain the Python FastAPI backend for QueryMind AI.

## Planned Stack
- **Framework:** FastAPI
- **ORM:** SQLAlchemy
- **AI/NLP:** LangChain + LLM (GPT / Gemini / Llama)
- **Auth:** JWT-based authentication
- **Databases:** MySQL, PostgreSQL, MongoDB
