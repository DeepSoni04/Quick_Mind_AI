# QueryMind AI

**Natural Language Database Assistant**

QueryMind AI enables users to interact with databases using natural language. Convert English/Hinglish queries into SQL, retrieve data securely, and visualize insights with an intuitive chat interface.

## Project Structure

```
Quick_Mind_AI/
├── frontEnd/          # React-based UI (Vite + React)
├── backEnd/           # Python FastAPI backend (coming soon)
└── README.md
```

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React, Vite, CSS3 |
| Backend | Python, FastAPI, LangChain |
| Database | MySQL, PostgreSQL, MongoDB |
| Auth | JWT + Role-Based Access Control |
| Deployment | AWS EC2 |
